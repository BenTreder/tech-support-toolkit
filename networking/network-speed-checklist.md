# Network Speed Checklist

## Run Speed Test

Check:

- Download speed
- Upload speed
- Latency

---

## Compare Wired vs Wireless

Test:

- Ethernet connection
- Wi-Fi connection

---

## Common Problems

- Too many connected devices
- Old router
- ISP throttling
- Poor router placement

---

## Solutions

- Upgrade router
- Move router
- Reduce congestion
- Upgrade internet plan
