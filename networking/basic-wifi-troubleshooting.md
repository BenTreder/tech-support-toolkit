# Basic Wi-Fi Troubleshooting

## Restart Equipment

Restart:

- Router
- Modem
- Device

---

## Check Signal Strength

Move closer to router if needed.

---

## Verify ISP Issues

Check if internet provider is down.

---

## Test Other Devices

See if issue affects:

- One device
- Multiple devices

---

## Basic Fixes

- Forget Wi-Fi network
- Reconnect
- Update router firmware
- Change Wi-Fi channel
