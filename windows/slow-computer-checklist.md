# Slow Computer Checklist

## Basic Fixes

- Restart the computer
- Check available storage
- Update Windows
- Update browser
- Close unnecessary apps

---

## Startup Programs

Check Task Manager:

```txt
Startup Apps
```

Disable unnecessary startup programs.

---

## Storage

Remove:

- Temporary files
- Large unused downloads
- Old installers
- Unused applications

---

## Malware Scan

Run:

- Windows Defender
- Malwarebytes
- Other trusted scanners

---

## Hardware Check

- Failing hard drive
- Low RAM
- Overheating issues
